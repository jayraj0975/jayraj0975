## 2. The competitor attacks

### "GitHub adds this tomorrow"
They would ship an "AI attribution" view for Copilot commits and a nicer SBOM export. What survives: (1) the buyer does not trust a report the seller's own vendor produced about the seller's own tool usage; (2) acquired companies are rarely GitHub-only (GitLab, Bitbucket, Azure DevOps, ZIPs from contractors); (3) AI evidence from Cursor, Claude Code, Codex, Devin and git-ai lives in formats GitHub has no incentive to rank neutrally; (4) the transaction workflow (seller runs, buyer verifies, questions routed to counsel) is not a platform feature. What does not survive: any part of our value that is "SBOM + CVEs + secrets". We treat those as inputs, never as the product.

### "Snyk or Black Duck adds this tomorrow"
Black Duck is the real threat: it already owns M&A OSS audits. It can add provenance ingestion in a quarter. What survives: price point and delivery model. Black Duck's audit model needs the code shipped to an auditor; ours runs where the code lives and emits a reproducible, signed evidence bundle. We should expect Black Duck to compete on the buy side and lose the self-serve seller side.

**Second research loop (September 2026):**
- **Sellers are targeted too.** Black Duck's M&A page now names sellers as customers and "AI" as audit scope, and says targets trust it with their IP. The seller side isn't uncontested, and the "targets won't share code" argument only holds for sharing *with the buyer*.
- **Where we compete.** Self-serve speed and price, continuous custody, a reproducible signed artifact, and graded AI evidence. Not audit depth or snippet matching, where Black Duck is stronger. See DECISIONS.md D11.

### "A tool vendor's attribution becomes the standard"
Editors and agents now write attribution into git themselves, and the second loop showed how that fails: VS Code stamped Copilot co-author trailers on commits with no AI involvement (MARKET.md row 11). Any competitor that counts trailers inherits that error. Our answer is grading (editor-inserted trailers are corroborating only, rule AI-013). If one vendor's format did become reliable and universal, it would make our AI section easier, not unnecessary: the neutral, cross-vendor, signed view stays ours to offer.

### "A well-funded YC clone"
Code is copyable in months. The only things that are not: (a) the history of signed snapshots each customer has accumulated with us (a chain of custody cannot be backfilled), (b) the set of buyers who already accept our format, and (c) the anonymised corpus of findings and their resolutions across transactions. All three are zero on day one. **This is the honest weakness.** Speed to the first 50 buyers accepting the format is the moat race.

### "A major law firm packages the workflow"
They need a fact engine; they will buy one. Law firms are a channel.

### "An M&A platform (Datasite, Intralinks) acquires a competitor"
Plausible exit path for us as well. The data room is where dossiers end up; we should integrate with data rooms, not compete with them.

## 3. Where the moat has to come from

Not from: AI, UI, prompts, LLMs, API aggregation, charts.

From:

1. **Contemporaneous evidence.** AI attribution, review evidence and state of the code can only be captured close to when they happen. Git notes get dropped by clones, trailers get squashed, agent logs expire. A customer with 18 months of signed snapshots has something a new vendor cannot recreate.
2. **Reproducibility as the verification protocol.** Because the analysis is deterministic, any party with access to the same commit can re-run the open analyzer and get a byte-identical dossier digest. That is what lets a buyer trust a seller-run scan without receiving the code, and it is expensive for a detection-based (probabilistic) competitor to match.
3. **Two-sided format adoption.** Every buyer who requests an AcquiCode dossier creates sellers; every seller who arrives with one educates a buyer.
4. **Outcome corpus.** Which findings actually moved price, created escrows, or were resolved by a counsel memo. Opt-in, anonymised, and only valuable after hundreds of transactions.
